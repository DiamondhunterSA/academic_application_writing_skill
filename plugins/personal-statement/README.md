# personal-statement

Assist in writing, structuring, and polishing personal statements and self-introductions. Use for drafting or revising a PS, personal statement, self-introduction, application essay, motivation letter, statement of purpose, cover letter, or personal bio for study abroad, graduate/PhD admissions, scholarships, jobs, or similar applications. Package-wide requirements and cross-document consistency reviews are outside this skill's focus.

## Installation

Run from the project where you want to use this skill.

### Claude Code

Install this skill with one command:

```bash
claude plugin install personal-statement --marketplace DiamondhunterSA/academic_application_writing_skill --scope project
```

Alternatively, add the marketplace and install the skill in two steps:

```bash
claude plugin marketplace add DiamondhunterSA/academic_application_writing_skill
claude plugin install personal-statement@DiamondhunterSA-academic-application-writing --scope project
```

### npx skills

```bash
npx --yes skills add DiamondhunterSA/academic_application_writing_skill --skill personal-statement --agent claude-code --yes
```
