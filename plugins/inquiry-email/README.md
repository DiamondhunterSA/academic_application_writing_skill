# inquiry-email

Draft, revise, and personalize inquiry emails (including enquiry emails and academic outreach) to prospective supervisors, research groups, admissions or funding offices, and contacts for research or professional opportunities. Use for initial inquiries, follow-ups, or replies in an inquiry thread; full application essays, cover letters, and unrelated marketing or customer-support email are outside this skill's focus.

## Installation

Run from the project where you want to use this skill.

### Claude Code

Install this skill with one command:

```bash
claude plugin install inquiry-email --marketplace DiamondhunterSA/academic_application_writing_skill --scope project
```

Alternatively, add the marketplace and install the skill in two steps:

```bash
claude plugin marketplace add DiamondhunterSA/academic_application_writing_skill
claude plugin install inquiry-email@DiamondhunterSA-skills --scope project
```

### npx skills

```bash
npx skills add DiamondhunterSA/academic_application_writing_skill --skill inquiry-email -a claude-code -y
```
